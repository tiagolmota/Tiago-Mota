# Scientific & Academic Writing

## Structure (IMRaD for empirical; adapted for CS)
1. **Abstract** — problem, method, result, implication (150-250 words)
2. **Introduction** — context → gap → research question → contribution → outline
3. **Related Work** — group by theme, not chronology; critique, don't just describe
4. **Methodology / Design** — replicable; justify choices
5. **Results** — facts only, no interpretation
6. **Discussion** — interpret results, link to RQ, limitations, threats to validity
7. **Conclusion** — answer the RQ, future work (no new results)
8. **References** — consistent style throughout

## Citation Styles
| Context | Style | Tool |
|---------|-------|------|
| Computing/Engineering (ISLA) | IEEE | Zotero + IEEE CSL |
| Education/Social Sciences | APA 7th | Zotero + APA CSL |
| ACM venues | ACM | Zotero + ACM CSL |
| Thesis (PT) | usually APA or ISO 690 | check regulations |

### IEEE inline: `[1]`, `[2,3]`, `[4]–[7]`
### APA inline: `(Author, Year)`, `(Author et al., Year)`

## Academic Register (PT/EN)
- Avoid: "I think", "obviously", "clearly", "very"
- Use: "This study argues", "The evidence suggests", "Notably"
- Passive voice acceptable in methods: "Data were collected..."
- Hedging for claims: "may", "appears to", "tends to"
- Define all acronyms at first use

## Writing Process
1. Outline first (bullet points per section)
2. Write body sections before intro/abstract
3. Write abstract last
4. Self-review: each paragraph = 1 claim + evidence + link to next
5. Spell-check + grammar check (LanguageTool, Grammarly)
6. Reference check: every claim has a citation or is your own result

## Common Pitfalls
- Abstract repeats intro verbatim → write independently
- Related work = annotated bibliography → must compare/contrast
- Figures without captions → always: "Figure N. Description (Source)"
- Tables: title above, notes below
- Passive throughout when active is clearer → mix both
